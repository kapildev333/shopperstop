# Tasks

Six worker tasks, run top to bottom on branch `lane/core-P2-L4-stock-cart` in `.worktrees/core-P2-L4` (order per PLAN.md D24). Workers start after core-P2-L1, L2 and L3 have merged and this branch is rebased onto `origin/main`: task 1 needs only L1 to L3's migrations (`customers`, `stores`, `products`, `set_updated_at()`) plus L1's `sqlc.yaml` and `testdb`; tasks 2 and 3 need L2 and L3 merged in full (`store.Get`, L3's `pattern`, `imageURL`, tree assembly and `CategoryTree`); tasks 4 to 6 build on 1 to 3. Decisions below are design.md's numbers. Gates for every task, from the worktree root: `make test-core` passes; `PATH=$HOME/.local/node-v22.23.3/bin:$PATH make gen postman` leaves `git status` clean (commit the regenerated `packages/ui/src/api/core.d.ts` and `docs/postman/shopperstop-core.postman_collection.json` with the task, D19, D23); `openspec validate --all --strict` passes. Each task starts with its failing tests committed as `test: <scenario>`, then the smallest code as `feat: ...`; the worker ticks its boxes in the `feat` commit. Test fixtures insert stores, categories and products with plain SQL (column lists from 0003 and 0004) and unique names per test.
