# Tasks

Seven worker tasks, run in order on branch `lane/core-P2-L5-orders` in `.worktrees/core-P2-L5`. Workers start after core-P2-L2, L3 and L4 have merged and this branch is rebased onto `origin/main`; the team lead re-checks design.md "Assumptions" against the landed code first. Decisions are design.md's numbers. Gates for every task, from the worktree root: `GOFLAGS=-count=1 make test-core` passes; `PATH=$HOME/.local/node-v22.23.3/bin:$PATH make gen postman` leaves `git status` clean (commit the regenerated `packages/ui/src/api/core.d.ts` and `docs/postman/shopperstop-core.postman_collection.json` with the task, D19, D23); `openspec validate --all --strict` passes. Each task commits its failing tests first as `test: <scenario>`, then the smallest code as `feat: ...`, ticking its boxes in the `feat` commit. Route tests go through the real router (`srv`) with the fixtures of design Test strategy; every new route gets its `TestAuthGates` rows in the task that adds it.
