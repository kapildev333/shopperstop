# Tasks

Five worker tasks, run in order on branch `lane/core-P2-L2-stores-serviceability` in `.worktrees/core-P2-L2`, after the branch is rebased onto `core-accounts-auth` on main. Decisions are design.md's numbers. Gates for every task, from the worktree root: `make test-core` passes (gofmt, vet, `go test -race` on `shopperstop_core_test`); `openspec validate --all --strict` passes; `PATH=$HOME/.local/node-v22.23.3/bin:$PATH make gen` leaves nothing uncommitted. Tasks 2 to 5 change `openapi.json`, so they also run `make postman` and commit the regenerated `packages/ui/src/api/core.d.ts` (D19) in their `feat:` commit, and the Postman collection only under the rule the manager set for core-P2-L1. Tests are named as below; each starts red and is committed before the code (`test:` then `feat:`). App tests use their own stores and the pincode block named in design Test strategy.
