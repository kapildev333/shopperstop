## Goals / Non-Goals

**Goals:** a README a newcomer can follow on a fresh clone; a CLAUDE.md whose every stated rule matches the tree and PLAN.md; both checked mechanically by `check-docs.sh` in this change.

**Non-Goals:** screenshots, a Makefile change, edits to Spec 1 (frozen, D6) or PLAN.md, badges (the repo is private and Actions is disabled, so a badge shows nothing useful), a licence section (private repo).

## Decisions

1. **One check script stands in for tests.** Prose has no unit test and no dependency may be added. `check-docs.sh` (in this change folder, archived with it) turns every scenario of the delta into a `grep -F`, `make -n` or `test -e`; it fails on today's tree (37 failures) and is the red step. Ceiling: it checks presence of facts, not quality of prose; the reviewer reads for that.
2. **Quick start is `npm ci` once, then `make dev`.** The Makefile does not install npm dependencies and is out of scope. README says so plainly; a backlog request asks the platform manager to make `make dev` run `npm ci` when `node_modules` is absent, after which the README drops the line.
3. **Describe the intended result, mark what is pending.** `make dev` today migrates, runs the seed stub, starts core on :8080, and the web and admin targets print their skip lines. README names all three ports and says which apps are not on `main` yet, in one sentence that the area which lands the app deletes.
4. **Demo sign-ins are listed now, flagged as Phase 2.** They are Spec 2 §11 test accounts on the reserved `.local` domain, no personal data. README says they work once the Phase 2 seed lands (D15 stub until then).
5. **No `psql` assumption.** README's database step uses `docker exec -it shopperstop-postgres-1 psql -U shopperstop_core shopperstop_core` (the client inside the container) or any GUI client on `localhost:5432`. CLAUDE.md tells agents they never run docker and use a Go pgx client for ad-hoc checks (platform area plan, Found).
6. **Only link files that exist.** `docs/postman/...` and app paths appear in code spans, not links, until they land. Screenshot cells say pending; no image links.
7. **CLAUDE.md keeps its shape and section order;** edits are in place plus one new `## Commands` section after "What this directory is" (UniCourse puts commands in its opening section; a section is easier to scan). No section is rewritten beyond what a listed edit needs.
